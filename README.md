<h1> Data Analysis Project on Churn Analysis </h1>

This is a project following Rishabh Mishra's walkthrough

- [Rishabh Mishra's walkthrough](https://youtu.be/tTtI2arH214?si=2VeDz_QnK6-L8zHp)

<h2> Problem Statement </h2>

In the hyper-competitive OTT landscape (Netflix, Hotstar, Prime), retention is the only way to survive. You will
act as a Data Analyst tasked with identifying high-risk subscribers using a multi-dimensional dataset (Customer
demographics, Subscription tiers, and Support escalations) **to figure out why customers stop doing business with company.**

<h2> Tools Used </h2>

- **SQL & Python** - Data Preparation and Modeling, Data Analysis, Visualization and insights.
- **VS Code** - Development environment.
